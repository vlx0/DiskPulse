# DiskPulse

**Живые диски.** Сколько занято на томе и кто сейчас читает/пишет — без Диспетчера задач.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 9 — «Мониторинг»** · день 60.

---

## Возможности

- тома C: / D: / флешка: занято, свободно, %
- состояние диска (хорошо / внимание / плохо), как CrystalDiskInfo — через Windows Storage
- график суммарного IO процессов
- кто читает и пишет (КБ/с · МБ/с), интервал 0,5…10 с
- ⋯ у процесса: снять этот, снять все с таким именем, открыть папку
- только Win32, без pip

IO в списке — по всей системе. Windows не отдаёт «этот процесс пишет на D:».

## Установка

```powershell
git clone https://github.com/vlx0/DiskPulse.git
cd DiskPulse
pythonw run_diskpulse.pyw
```

Или `start.bat`.

Нужен Windows 10+ и Python 3.10+. Внешних зависимостей нет.
